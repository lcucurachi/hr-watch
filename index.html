Enable Bluetooth in your browser

HR Watch talks to your strap using Web Bluetooth, a browser feature that not every browser has. Find your browser below. Settings addresses can't be opened by a link, so copy them and paste them into the address bar.

Chrome Works Your browser

Works by default on Windows and Mac. If Connect doesn't find your strap:

  1. Turn Bluetooth on in your system settings.
  2. Mac only: System Settings → Privacy & Security → Bluetooth → allow Google Chrome.
  3. Open chrome://settings/content/bluetoothDevices and choose Sites can ask to connect to Bluetooth devices.
  4. Linux only: open chrome://flags/#enable-experimental-web-platform-features , set it to Enabled and press Relaunch.
Brave Needs a setting Your browser

Brave turns Web Bluetooth off by default. You'll see the error "Web Bluetooth API globally disabled".

  1. Open brave://flags/#brave-web-bluetooth-api
  2. Set Web Bluetooth API to Enabled.
  3. Press Relaunch at the bottom of the page.

Still not working? Check that Bluetooth is on in your system and, on Mac, that Brave is allowed under System Settings → Privacy & Security → Bluetooth.

Firefox Not supported Your browser

Firefox doesn't have Web Bluetooth, and there is no setting to turn it on. Open HR Watch in Chrome or Brave instead.

Safari (Mac) Not supported Your browser

Safari doesn't have Web Bluetooth, and there is no setting to turn it on. Open HR Watch in Chrome or Brave instead.

iPhone & iPad Needs an add-on Your device

Every browser on iPhone, Safari and Chrome included, runs on Apple's engine, which has no Web Bluetooth. One of these add-ons fills the gap:

Option 1: Bluefy (recommended)

  1. Install Bluefy – Web BLE Browser from the App Store (free).
  2. Open this app's web address in Bluefy.
  3. Allow Bluetooth when asked. If you said no: Settings → Bluefy → turn on Bluetooth.

Option 2: WebBLE Safari extension (iOS 26 or later)

  1. Install WebBLE from the App Store.
  2. Open Settings → Apps → Safari → Extensions → WebBLE and turn it on.
  3. Open this app in Safari and allow WebBLE on this website when asked.

WebBLE support in HR Watch hasn't been tested yet. If it doesn't connect, use Bluefy.

Important: on iPhone the app must be opened from an https:// address (for example GitHub Pages). An address from your computer's local network won't work.
